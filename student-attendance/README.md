# 守课 · 学生打卡考勤系统

基于 React + Vite + TypeScript 的学生打卡考勤前端工程。

## 功能页面

- **登录**：管理员 / 普通用户 / 学生登录后进入系统
- **首页总览**：今日出勤率、到勤统计、最新打卡摘要
- **今日打卡**：学生打卡情况表格（姓名/学号/班级/状态筛选）
- **学生管理**：在册学生列表（仅管理员可见，可增删改）
- **审批请假**：查看全部请假申请，可审批通过或驳回；已通过、已拒绝也可再改状态（仅管理员可见）
- **考勤记录**：历史打卡明细（管理员可增删改、表格批量导入）
- **申请请假**：学生提交请假申请并查看申请记录（仅学生可见）

## 演示账号

| 用户名 | 密码 | 角色 | 可见菜单 |
|--------|------|------|----------|
| `admin` | `123456` | 管理员 | 首页总览、今日打卡、学生管理、审批请假、考勤记录 |
| `user1` | `123456` | 普通用户 | 首页总览、今日打卡、考勤记录（无学生管理） |
| `student1` | `123456` | 学生（小小胖，高三（1）班） | 申请请假 |

在「学生管理」中新增的学生，登录名为**学号**，默认密码为 `123456`，登录后同样只可见「申请请假」。

批量导入模板请点「下载模板」，可选 `.xlsx` 或 `.xls`。必要列为 `id`、`studentId`、`date`、`status`（也可用「记录ID / 学生ID / 日期 / 状态」）。已有 `id` 会覆盖，新 `id` 会新增。

## 快速开始

```bash
cd student-attendance
npm install
npm run dev
```

## 构建打包

```bash
npm run build
npm run preview
```

## 前后端联调

1. 启动后端：`cd ../attendance-api && npm install && npm run dev`（端口 3001）
2. 启动前端：`npm run dev`（Vite 已将 `/api` 代理到后端）

前端请求封装见 `src/api/index.ts`。
